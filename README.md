# Static Site Generator

A powerful and flexible static site generator built with Python. Convert your markdown files and templates into a complete static website.

## Features

- **Markdown Support**: Write content in markdown and automatically convert to HTML
- **Template System**: Use Jinja2 templates for consistent site layout
- **Fast Build**: Efficiently generate your entire site from source files
- **Customizable**: Easy configuration and extensible architecture
- **Asset Management**: Automatically copy static assets to output directory

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/static-site-generator.git
cd static-site-generator
```

## Usage

Generate your static site:

```bash
python main.py
```

or

```bash
./main.sh
```

## Project Structure

```
.
├── content           # Markdown files
├── src/              # Logic and Test Files
├── static/           # Static assets (CSS, images, etc.)
└── docs/             # Generated HTML output
```

## Requirements

- Python 3.8+
